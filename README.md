# Linguist AI

Linguist AI is a warm, supportive English learning tutor designed to help users improve their language skills through natural conversation, adaptive testing, and CEFR-based scaffolding.

## Features

- **Empathetic AI Tutor**: A caring personality that supports users emotionally and linguistically.
- **CEFR-Based Leveling**: Selectable levels from A1 to C2.
- **Level + 1 Method**: Automatically introduces slightly more advanced vocabulary with synonyms to help you grow.
- **Interactive Tests**: Multiple choice, open-ended, and written tests generated on the fly.
- **Glassmorphism UI**: A beautiful, modern interface with dynamic animations.
- **Voice Integration**: Supports speech-to-text and text-to-speech for an immersive experience.

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animations**: Framer Motion
- **AI Model**: DeepSeek Chat (via OpenAI-compatible API)
- **State Management**: React Hooks

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/NurdauletE/linguist-ai.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your environment variables:
   - Create a `.env.local` file.
   - Add `DEEPSEEK_API_KEY=your_api_key_here`.
4. Run the development server:
   ```bash
   npm run dev
   ```
