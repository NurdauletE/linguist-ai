# Инструкция по установке Linguist AI

## Перенос на другой компьютер

### 1. Что скопировать
Скопируйте **всю папку проекта** на новый компьютер (через флешку, облако и т.д.). Папку `node_modules` копировать **не обязательно** — установщик создаст её заново.

### 2. Что установить на новом компьютере
- **Node.js LTS** — скачать с [nodejs.org](https://nodejs.org/)
- Браузер **Chrome** или **Edge** — для работы Speech-to-Text

### 3. Запуск установщика
1. Откройте папку проекта
2. Запустите **Установщик.bat** (двойной клик)
3. Дождитесь завершения — скрипт установит все зависимости
4. Если появился файл `.env.local` — откройте его и вставьте ваш `DEEPSEEK_API_KEY` (получить: [platform.deepseek.com](https://platform.deepseek.com/))

### 4. Запуск приложения
Запустите **Запуск Linguist AI.bat** или выполните в терминале:
```bash
npm run dev
```
Откройте в браузере: http://localhost:3000

---

## Что делает установщик
- Проверяет наличие Node.js и npm
- Устанавливает все зависимости (`npm install`)
- Создаёт `.env.local` из шаблона, если его нет
- Очищает кэш сборки для чистого старта

---

## Если Speech-to-Text не работает
- Используйте **Chrome** или **Edge**
- Откройте сайт по адресу **localhost:3000** (не по IP)
- Разрешите доступ к микрофону в браузере
- Убедитесь, что есть доступ в интернет
